# RE4 Tweaks PS2 Installer (Android)

An Android app that combines every step of installing [RE4 Menu Tweaks PS2](#credits--source)
into a single tool: it reads your PS2 ISO, extracts the boot executable, applies the
patch, and injects the result back — without needing Winlator or manually running
a `.bat` file.

## What it does

1. You pick your game's ISO file from inside the app.
2. The app auto-detects the region (SLES / SLUS / SLPM) from the boot executable's
   filename at the root of the ISO.
3. You choose which menu language to install: the **original** Portuguese menu, or
   the **English translation**.
4. It extracts the executable, runs it through the exact same verification and
   patch logic as the original PC/Winlator installer (unmodified), and injects the
   patched result into a brand-new output ISO.
5. **Your original ISO is never touched** — the app only ever writes to a new file.

## Two menu variants included

This app ships **both** versions of the menu text table, selectable at install time:

- **Original** — the stock Portuguese menu exactly as shipped by the tweak's
  original authors.
- **English** — a full English translation of the menu's on-screen text (tab
  titles, options, colors, weapons, outfits, etc.), translated by **YEMENI**.
  Only the text strings were changed; no code, offsets, hooks, or binary
  structure were touched. See
  `app/src/main/python/dados_en_root/dados/TRANSLATION_NOTE.txt` for the exact
  technical details, including which specific files were deliberately left
  untranslated and why (they're checked against a fixed hash by the installer's
  own integrity checks, and translating them would make every install attempt
  fail that verification).

## Technical structure

- **Kotlin** — UI and orchestration (file picking, background threading, result
  display)
- **Python**, via [Chaquopy](https://chaquo.com/chaquopy/) — the actual patch
  logic, copied from the original installer tool without modification
- **[pycdlib](https://github.com/clalancette/pycdlib)** — reading and writing the
  ISO9660 filesystem

Both menu variants ship as complete, independent copies of the installer logic
(`installer_core.py` + `FilesUsed.py` + `RemoveWeaponSwap.py` + `dados/`) rather
than one shared copy with a swapped data folder. This was a deliberate choice —
it means the original, security-relevant patch logic never has to be touched to
support the translation, and stays byte-identical to the upstream PC tool in
both cases.

Full in-code documentation (explaining every technical decision) lives in:
- `app/src/main/python/iso_handler.py`
- `app/src/main/java/.../MainActivity.kt`

## Building (GitHub Actions)

This repo includes `.github/workflows/build.yml`, which builds a debug APK
automatically on every push to `main` and can also be triggered manually from
the **Actions** tab (workflow_dispatch). Once it finishes, download the APK
from the workflow run's **Artifacts** section.

Note: this repo does **not** include a real `gradle/wrapper/gradle-wrapper.jar`
(it's a binary file normally generated by opening the project once in Android
Studio, which wasn't available while writing this). The workflow installs
Gradle directly instead of relying on `./gradlew`. If you open this project in
Android Studio locally, it will generate a real wrapper for you, at which
point you can switch the workflow back to using `./gradlew` if you prefer.

The debug APK is signed with Gradle's built-in debug keystore — fine for
testing on your own device, but not meant for public release as-is. No release
signing config has been set up yet.

## Project status
